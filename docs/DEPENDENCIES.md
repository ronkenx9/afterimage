# Dependencies

- Next.js and React: product UI and server routes.
- Motion: reduced-motion-aware timeline and evidence drawer transitions.
- Phosphor Icons: one consistent accessible icon family.
- Decimal.js: decimal-safe quantity and money calculations.
- Zod: validation at external and order boundaries.
- Vitest and Playwright: logic, integration, desktop, and mobile verification.

Versions are pinned by `pnpm-lock.yaml`. The application targets Node 22 or newer and defaults to paper execution.
